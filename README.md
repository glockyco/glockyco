# Johann Glock

I'm a researcher and senior software engineer at the Software Competence Center Hagenberg (SCCH), and a PhD candidate in Informatics at the University of Klagenfurt. My research applies formal program analysis to semantic differencing and software test generalization.

My research tools include [PASDA](https://github.com/glockyco/PASDA) for semantic differencing and [Teralizer](https://github.com/glockyco/Teralizer) for turning unit tests into property-based tests.

Outside research, I build game maps, compendiums and mods:

- [Compendiums](https://compendiums.org/) links to the public game references.
- [Erenshor Community Tools](https://github.com/glockyco/erenshor-data-mining) covers maps, mods and wiki tooling.
- [Ancient Kingdoms](https://ancient-kingdoms.compendiums.org/) and [Afallon](https://afallon.compendiums.org/) have searchable compendiums and interactive maps.
- [HotRepl](https://github.com/glockyco/HotRepl) is a runtime C# REPL and command bridge for Unity games.

My [website](https://glockyco.com/) has my projects, publications and CV.
